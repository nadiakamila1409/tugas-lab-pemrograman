# Seleksi 5 Ide Paling Layak
Lima ide terpilih memiliki fitur inti berupa operasi dasar data (tambah, lihat, ubah, hapus), pencarian atau filter, dan laporan sederhana. Semuanya dapat dibangun dengan HTML, CSS, JavaScript, serta satu bahasa backend dan database yang umum diajarkan di perkuliahan dasar. Peringkat disusun dari yang paling mudah.

# Peringkat 1 — Pencatat keuangan pribadi mahasiswa
Ide asal: 18
Fitur inti versi dasar (MVP): Catat pemasukan dan pengeluaran, kategori, batas anggaran bulanan, ringkasan grafik sederhana
Sumber pendapatan: Freemium (fitur premium berbayar)

# Peringkat 2 — Direktori makanan murah sekitar kampus
Ide asal: 34
Fitur inti versi dasar (MVP): Daftar warung dan menu, filter harga dan jarak, ulasan sederhana, halaman admin
Sumber pendapatan: Listing berbayar dan iklan warung

# Peringkat 3 — Portal info magang, lomba, dan beasiswa
Ide asal: 6
Fitur inti versi dasar (MVP): Daftar info, pencarian dan filter, tanggal penutupan, halaman admin
Sumber pendapatan: Listing berbayar dan iklan

# Peringkat 4 — Pelacak status laundry
Ide asal: 37
Fitur inti versi dasar (MVP): Input pesanan, status cucian (diterima, dicuci, siap diambil), hitung biaya, riwayat pelanggan
Sumber pendapatan: Langganan bulanan pemilik laundry

# Peringkat 5 — Manajemen kos untuk pemilik
Ide asal: 25
Fitur inti versi dasar (MVP): Data kamar dan penghuni, catatan pembayaran sewa, status lunas atau menunggak, laporan bulanan
Sumber pendapatan: Langganan bulanan per jumlah kamar

# Alasan Pemilihan
1. 	Pencatat keuangan pribadi. Logikanya hanya penjumlahan dan pengelompokan data, tanpa pihak luar. Datanya milik satu pengguna sehingga tidak perlu sistem peran yang rumit, dan hasil akhirnya langsung bisa dipakai teman sekelas sebagai pengguna uji.
2. 	Direktori makanan murah. Berupa situs konten dengan pencarian dan filter, sehingga fokus pada tampilan dan pengelolaan data. Masalahnya dirasakan semua mahasiswa dan datanya bisa dikumpulkan langsung dari warung sekitar kampus tanpa integrasi pihak ketiga.
3. 	Portal info peluang. Alurnya sederhana: admin memasukkan info, mahasiswa mencari dan memfilter. Risiko teknisnya rendah dan ruang pengembangan tampilan luas.
4. 	Pelacak status laundry. Alur kerjanya linear dengan beberapa status, sehingga melatih logika kondisi dan pembaruan data. Laundry di sekitar kos mudah dijadikan pengguna uji, dan tidak memerlukan pembayaran daring maupun perangkat keras.
5. 	Manajemen kos untuk pemilik. Ini latihan klasik CRUD dengan relasi antar tabel (kamar, penghuni, pembayaran). Aturan bisnisnya jelas dan pemilik kos mudah dijumpai untuk wawancara kebutuhan, meski sedikit lebih kompleks dibanding empat ide lainnya.
