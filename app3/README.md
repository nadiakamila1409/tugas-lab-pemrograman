# KampusHub — Portal Info Magang, Lomba, dan Beasiswa
KampusHub adalah aplikasi web terpusat yang dirancang untuk membantu mahasiswa menemukan informasi magang, lomba, dan beasiswa dengan lebih cepat, rapi, dan terstruktur dalam satu platform.

# 📌 Latar Belakang Masalah
Mahasiswa sering kali kesulitan memantau berbagai peluang pengembangan diri karena informasi magang, lomba, dan beasiswa tersebar di banyak kanal yang terpisah (media sosial, grup pesan, poster digital, hingga situs masing-masing penyelenggara). Akibatnya, banyak peluang yang terlewat, sulit disaring sesuai kebutuhan, dan tenggat pendaftaran (deadline) kerap terabaikan.

# 💡 Solusi
Menghadirkan portal informasi satu pintu yang menyajikan daftar peluang dalam format kartu yang mudah dibaca, dilengkapi fitur pencarian, filter kategori, penanda batas waktu pendaftaran, serta dashboard khusus admin untuk memperbarui katalog informasi secara berkala.

# 🔄 Alur Aplikasi
1. Alur Mahasiswa (Pengguna Umum)
  a. Membuka halaman utama portal untuk melihat daftar peluang yang tersedia.
  b. Menggunakan kolom pencarian atau filter (kategori program, sistem pelaksanaan, dan status pendaftaran).
  c. Menyimpan peluang menarik ke daftar Tersimpan (Bookmark) untuk ditinjau kembali.
  d. Membuka detail program untuk membaca persyaratan lengkap dan melanjutkan ke tautan pendaftaran resmi.

2. Alur Admin (Pengelola Konten)
  a. Masuk ke Mode Admin menggunakan PIN autentikasi.
  b. Menambahkan informasi peluang baru melalui formulir terstruktur.
  c. Mengubah (update) informasi yang mengalami perubahan jadwal/syarat, mengatur status sorotan (featured), atau menghapus data yang sudah kedaluwarsa.

# ✨ Fitur Utama (MVP)
1. Katalog Peluang Terkurasi: Menampilkan judul program, kategori (Magang, Lomba, Beasiswa), penyelenggara, sistem pelaksanaan (Online/Hybrid/Onsite), benefit, dan tanggal penutupan.
2. Pencarian & Filter Berlapis: Pencarian kata kunci instan serta penyaringan berdasarkan kategori, sistem kegiatan, status buka/tutup, dan urutan prioritas.
3. Indikator Deadline Otomatis: Penanda visual untuk peluang yang masih dibuka, segera tutup ($< 7$ hari), maupun yang sudah ditutup.
4. Bookmark / Simpan Favorit: Mahasiswa dapat menyimpan daftar peluang pilihan di browser tanpa perlu registrasi akun yang rumit.
5. Dashboard Admin (CRUD): Fitur tambah, lihat, ubah, dan hapus data peluang lengkap dengan opsi Featured / Paid Listing.
